# ADR-0006 M0-M3 集成与安全门禁（TASK-006）

状态：已接受　日期：2026-09-01　关联任务：TASK-006

## 决策

### 1. 门禁组合（make verify-m0-m3）

串联既有切片验收目标，不新增隐藏实现：

```
verify-foundation        # fmt/vet/build/test/race（全部包）
verify-identity-slice    # 身份闭环（真实 PG/Redis）
verify-llm-kernel-spike  # Bifrost 内核安全门禁/回退/取消/用量
verify-mcp-slice         # MCP 发现/执行隔离 + 凭据引用（真实 PG/Redis）
integration-m0m3         # 跨切片旅程（下条）
portal-check + build/guard + e2e   # Portal 壳与浏览器流
```

### 2. 跨切片旅程（TestM0M3JourneyIntegration）

一个公共端点完成验收链：dev 登录（用户/成员同步）→ 创建 `agk_*` key → `POST /v1/chat/completions`（agk 鉴权 + Workspace 选择 + **token exchange** 签发并验回 aud=llm-gateway JWT → llmkernel fail-closed 门禁 → Provider 桩；用量钩子记录）→ `POST /mcp/gitlab` tools/call（凭据仅服务端注入，响应无凭据）→ 吊销 key 后**三个面全部立即 401**。审计断言：auth 失败、MCP 允许、key 创建/吊销、trace_id 透传落库。

### 3. `/v1/chat/completions` 的定性

该端点是已交付产物的**集成胶水**（TASK-002 内核 + TASK-001 协议契约类型 + TASK-003 鉴权），不引入新的 Provider/协议实现；M2 里程碑在此面上扩展 Responses/Anthropic/流式。

### 4. 基线 Policy 与 DLP 引擎

- `packages/policy`：Allowlist（工作空间 + 模型白名单，deny by default）。M5 替换规则源，决策词汇与 fail-closed 契约不变。
- `packages/dlp`：正则基线（OpenAI/AGK key、Bearer、密码字段、私钥、DB 连接串、手机号、内网 IP）。M5 扩展覆盖与脱敏。
两者均实现 llmkernel 的引擎接口；引擎故障即拒绝（已在 llmkernel 契约测试覆盖）。

### 5. 运行时归属唯一性

LLM 数据面唯一实现 = `packages/llmkernel`（bifrost Core 内核，ADR-0004）；MCP 治理唯一实现 = `packages/mcpgateway`（ADR-0005）；xingding-llmg runtime 退役、xingding-mcpa 为语义来源（不可依赖，ADR-0005）。依赖与许可证盘点见 `docs/dev/DEPENDENCIES.md`。

## 已知边界（进入 M4 前的遗留）

- LLM 流式 HTTP 端点未开放（内核流式已验证，HTTP SSE 属 M2 收尾）。
- 跨 Workspace 发现的"拒绝"以过滤实现 + 显式调用落审计；纯列表请求不逐次落审计（噪声控制）。
- bifrost v1.8.4 流式取消上游竞态（ADR-0004，诊断目标跟踪）。
